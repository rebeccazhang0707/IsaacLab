# Shoelace task assets

`collider_simplified.usd` is a collision-only derivative of `collider.usd`. Its closed shoe shell was reduced
from 28,106 to 8,000 triangles with quadric decimation while preserving the original scale, winding, and prim
path. The source collider comes from
[`newton/examples/assets/shoelace`](https://github.com/newton-physics/newton/tree/7daf8324dbe1ca6301a3440f4b1204e3158c2369/newton/examples/assets/shoelace)
at Newton commit `7daf8324dbe1ca6301a3440f4b1204e3158c2369`. The visual shoe remains sourced from Newton's
`model.usd`.

The USD files, textures, and settled segment poses are bundled as package data so the task also works
from an installed wheel. Fetch Git LFS assets before building a source checkout.

`settled_tail_clear_segment_poses.npz` contains the task's offline gravity-settled initial poses.
Its `shoelace_left` and `shoelace_right` keys each store 79 segment poses as position [m] followed
by an x-y-z-w quaternion. This NPZ and the source curve are used only by offline asset generation,
not loaded by runtime startup or reset events.

`shoelace.usda` is the unified runtime asset generated by `../generate_asset.py` from these source
assets. It contains the shoe, pinned span, two free cables, their physical attributes, collision
filters, and the reference/settled data required by startup events. Each
`/Shoelace/Shoelace{Left,Right}/geometry/mesh` retains its `BasisCurves` geometry and stores:

- `shoelace:referenceOrientations` (`Float4Array`, 79 xyzw quaternions): parallel-transport frames
  computed on the entire resampled centerline, then sliced for the left or right free cable.
- `shoelace:referenceSegmentLength` (`Double`): mean original 450-segment length [m].
- `shoelace:segmentLength` (`Double`): mean resampled 360-segment length [m].
- `shoelace:settledPositions` (`Point3fArray`, 79 positions [m]): the corresponding NPZ positions.
- `shoelace:settledOrientations` (`Float4Array`, 79 xyzw quaternions): the corresponding NPZ orientations.

All poses in these attributes are local to their curve prim. The generator checks that the prototype
curve transforms are identity, validates array shapes and finite values, and rejects non-unit
quaternions. Startup events read these five attributes and transform poses to the environment's
world frame; resets translate the installed defaults together with the shoe while preserving anchors.

The asset uses local segment indices; no training environment indices are stored. Textures remain
external dependencies referenced by relative paths, so copying only `shoelace.usda` is not sufficient
for textured rendering. Native segment masses also supply geometric inertia. The generator uses
existing native material/collision configurations without custom `isaaclab:cable:*` attributes or
Dahl parameters. Task-specific body/joint overrides and the cable contact-import fallback are applied
by startup events; the coupled VBD solver leaves Dahl friction disabled. Regenerate the asset with:

```bash
PXR_WORK_THREAD_LIMIT=1 uv run python -m isaaclab_tasks.contrib.shoelace.generate_asset
```
